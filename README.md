# KK Verse Studio

An AI video editing studio that runs inside Claude Code, built for KK Create.

Drop in a talking-head clip, type one command, get back a finished short-form video:
captions timed to your voice, effects that sit behind your head, and sound design.
Claude listens to the clip, plans the edit, checks its own frames, and renders. You approve.

```
/kk-reel my-clip.mp4
/kk-captions truck-art, highlight the numbers, a bit higher
/kk-effects orbit from 3 to 6 seconds
/kk-effects spotlight when I say "kill the lights", with the word LIGHTS behind me
/kk-sfx add a whoosh when I say "here's the thing"
```

The result is saved next to your clip as `my-clip_kkverse.mp4`. Your original is never touched.

## What is in the box

| | |
| --- | --- |
| **10 caption styles** | `kk-pop` · `karaoke` · `marker` · `typewriter` · `newsroom` · `one-word` · `pill` · `editorial` · `truck-art` · `clean` |
| **17 effects** | camera: `punch-in` `slow-push` · behind you: `big-word` `spotlight` `orbit` `wall-text` · overlays: `headline` `lower-third` `checklist` `counter` `comment` `stamp` `callout` `source-tag` `follow-cta` `progress` · colour: `grade` |
| **15 sounds** | `whoosh` `swish` `pop` `click` `tick` `typing` `ding` `success` `sparkle` `thud` `boom` `riser` `error` `shutter` `scribble` |

Made for how KK Create works:

- **English, Hindi and Hinglish.** Devanagari renders in a proper heavy display weight; Claude can caption Hinglish in Roman or Devanagari.
- **Indian numbers.** The counter writes `₹45,00,000` or `₹45 L` / `1.2 Cr`.
- **Explainer tools.** `newsroom` captions, `MYTH` / `FACT` stamps and `source-tag` citation chips. Claude is told never to invent a source, and to offer the KK Create fact-check first when it is available.
- **Timed by what you say.** `--at "@that is a myth"` puts an effect on the exact word.
- **Graphics behind the speaker.** The studio cuts the person out and tracks the head, so a giant word or a spotlight goes between you and your wall.
- **Sound with nothing to license.** Every sound is generated by the studio itself; effects arrive with a matched sound, mixed under the voice.
- **Everything runs on your machine.** No video is uploaded anywhere. No extra subscription: it uses the Claude plan you already have.

## Install

You need [Claude Code](https://claude.com/claude-code). The setup installs the rest (ffmpeg, fonts, a speech model, tracking models) the first time; allow a few minutes and about 1 GB.

**On your own computer (works in every folder):**

```bash
git clone https://github.com/kkcreatemate/AIWo-Audience-Interest ~/.kkverse
bash ~/.kkverse/studio/install.sh
```

Restart Claude Code, drag a video into the chat, type `/kk-reel`.

**Or just open this repository in Claude Code** (desktop, terminal or web). The four skills are picked up automatically; the first command runs the one-time setup.

Requirements: macOS, Linux or Windows (Git Bash / WSL) · Node 18+ · Python 3.9+ · Google Chrome or the bundled Chromium.

## How it works

```
your clip ─┬─ speech → word timings (faster-whisper)          ┐
           ├─ person cut-out + head track (MediaPipe)          ├─ edit.json  (what happens when)
           └─ Claude: fixes the transcript, plans the edit     ┘
                                   │
     captions + effects drawn as HTML, frame by frame, in headless Chrome
                                   │
     ffmpeg stacks:  room → back layer → you (cut out) → front layer   + camera moves, colour, sound
                                   │
                         my-clip_kkverse.mp4
```

Each video gets a small `my-clip.kkv/` folder beside it holding the transcript, the edit and cached tracking. Delete it any time.

The engine is a plain command-line tool, `kkv`, so you can also drive it by hand:

```bash
studio/bin/kkv words    clip.mp4 --lang hi
studio/bin/kkv captions clip.mp4 kk-pop --key "45 lakh,myth"
studio/bin/kkv fx       clip.mp4 add big-word --at "@that is a myth" --text MYTH
studio/bin/kkv frames   clip.mp4          # check sheet before rendering
studio/bin/kkv render   clip.mp4
studio/bin/kkv list                       # the whole catalog with every option
studio/bin/kkv gallery                    # one-page preview of every style and effect
```

## Make it yours

- **A new caption style** is one block in [`studio/web/captions/styles.js`](studio/web/captions/styles.js): how to build a line, and what it looks like at time `t`.
- **A new effect** is one block in [`studio/web/effects/`](studio/web/effects/). Ask Claude: *"add an effect called price-tag that …"* and it can write it in the same pattern.
- **Brand colours and fonts** live at the top of [`studio/web/lib/core.js`](studio/web/lib/core.js).

## Honest notes

- It drafts, you approve. Watch the result and tell Claude what looks wrong.
- Behind-the-head effects depend on a clean view of the speaker; busy backgrounds, fast hands and fine hair can show rough edges.
- Speech recognition makes mistakes with names and mixed Hindi-English. Claude reads the transcript and corrects it, and you can too.
- HDR iPhone clips are tone-mapped when your ffmpeg supports it; otherwise export as SDR.
- Claude cannot hear. It places sounds by rule and tells you what it placed; you are the ears.
