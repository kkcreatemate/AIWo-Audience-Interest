# /kk-sfx · sound design

Request: $ARGUMENTS

## Find the studio and the video

```bash
KKV="$(command -v kkv || true)"
for d in "${CLAUDE_PROJECT_DIR:-$PWD}/studio" "$PWD/studio" "$HOME/.kkverse/studio"; do [ -z "$KKV" ] && [ -x "$d/bin/kkv" ] && KKV="$d/bin/kkv"; done
"$KKV" doctor      # anything missing → bash "$(dirname "$KKV")/../setup.sh" (one time), then continue
"$KKV" list sounds
```

The video is the path in the user's message or their attachment; if there is none, use the newest video in the working folder or ask.

## How sound works here

- Every sound is generated by the studio itself, so there is nothing to license and nothing to download.
- The voice is never changed. Sounds are mixed underneath it.
- Effects added with `/kk-effects` already carry a matched sound (a whoosh on a punch-in, a thud on a stamp, pops as a checklist ticks). `"$KKV" sfx <video> fx off` silences those; `fx on` brings them back.

## Commands

```bash
"$KKV" sfx <video> add whoosh --at "@that is a myth"          # at a spoken phrase (needs: kkv words <video>)
"$KKV" sfx <video> add ding --at "12.4,end-1" --gain -12      # several times at once; gain in dB
"$KKV" sfx <video> add riser --at "@here it is-1.2" --dur 1.2 # build-up that ends as the phrase starts
"$KKV" sfx <video> keys                                       # a soft pop on every highlighted caption word
"$KKV" sfx <video> list | rm <n> | clear
"$KKV" render <video>
```

| Sound | Use it for |
| --- | --- |
| `whoosh`, `swish` | zooms, titles and cards arriving |
| `pop`, `click`, `tick` | words landing, list items, buttons |
| `typing` | text typing on screen (`--dur` = how long) |
| `ding`, `success`, `sparkle` | a reveal, a win, a final number |
| `thud`, `boom` | stamps, big words, hard cuts |
| `riser` | tension before a reveal (`--dur`) |
| `error` | wrong, myth, nope |
| `shutter` | freeze frames, screenshots |
| `scribble` | arrows and doodles drawing |

## Taste

- Default loudness is -10 dB under the voice. Keep accents between -16 and -8; only a single hero hit should go louder.
- A sound should land on the frame the thing happens, not after. For build-ups, end the `riser` exactly where the reveal starts.
- Do not put a sound on every word. Highlighted words, cuts and reveals are enough. If the user asks for "more energy", add sounds at the 3 to 5 strongest moments rather than everywhere.
- You cannot hear the result. Say so, tell the user exactly which sounds you placed and when, and ask them to listen for anything too loud. `"$KKV" sound ding -o ding.wav` exports one sound so they can audition it.
